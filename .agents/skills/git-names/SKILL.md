---
name: git-names
description: Предлагает имя ветки feat-N и короткое сообщение коммита для текущих незакоммиченных изменений в Wishlist.
---

Посмотри подготовленные к коммиту, неподготовленные и новые файлы в текущем репозитории. Если изменений нет, сообщи об этом.

Определи следующий номер фичи по максимальному номеру `feat-N` в локальной истории и известных Git ветках, включая ветки удалённого репозитория, доступные локально. Если таких номеров ещё нет, начни с `feat-1`.

Выведи в чат две строки:

- **Ветка** `feat-N/краткое-имя`. Замени вторую часть коротким английским названием в kebab-case, например `feat-3/wishlist-management`.
- **Коммит** `feat-N. Краткое описание изменений`. Используй тот же номер и уложи всё сообщение в 15 слов. Описание пиши на русском.

Выполняй только чтение. Не создавай ветку и коммит, не добавляй файлы в индекс и не меняй рабочее дерево.
